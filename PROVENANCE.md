# Project provenance

This repository packages Alexander Gaspar Manuel's local coursework project for a technical portfolio. Original course materials may include supplied scaffolding; this repository does not claim that every line was independently authored.

In September 2026, Codex assisted with source review, packaging, documentation and the specific corrections/verification described in the README. The original local coursework files were preserved. New tests and reproducibility scripts were added during that preparation.

No blanket open-source license is applied. Existing third-party notices remain applicable. This repository documents the work and does not grant rights to third-party course material or datasets.

## Media

The demo and calculation image were found alongside the original local coursework source. The source video's creation metadata is dated May 10, 2025. `countdown-demo.mp4` contains its final approximately 21 seconds, beginning at 00:47, with audio and source metadata removed and web compression applied. `countdown-demo.gif` is an 4 fps, 320-pixel-wide preview derived from that excerpt. Neither version changes playback speed. `systick-calculations.jpeg` preserves the original calculation image unchanged.

These are original project materials, not generated hardware imagery. The historical recording does not establish that the September 2026 source corrections have been flashed or tested on a board.
